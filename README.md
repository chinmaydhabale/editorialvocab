# EditorialVocab - Blogger Automation Bot 📚🚀

A specialized web application for generating high-quality, beautifully structured **Daily Editorial Vocabulary & Idioms** blog posts for Google Blogger.

## Features
- **Multi-Source Input**: Text paste, Article URL, Multiple newspaper page screenshots (Multimodal OCR).
- **AI Vocabulary Engine**: English/Hindi meanings, Synonyms, Antonyms, Memory Tricks (Mnemonics), Root Words, and Idioms.
- **Auto AI Thumbnail Banner Generator**: High-resolution cover thumbnails matching exact article titles.
- **Blogger Auto-Publishing**: 1-Click direct posting via Blogger API v3 or clean inline HTML copying.
- **High-Ranking SEO Titles**: Automatic title formatting with Newspaper Name, Today's Date, and Main Headline.
- **Latest Gemini Models**: Supports Gemini 3.6 Flash, 3.5 Flash, 2.5 Flash, 2.0 Flash with automatic API Key model discovery.

## Tech Stack
- React + Vite
- Vanilla CSS with Glassmorphic tokens & Hindi typography
- Google Generative AI SDK (@google/generative-ai)
- Lucide React Icons
